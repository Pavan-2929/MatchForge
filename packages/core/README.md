# MatchForge Core

A TypeScript toolkit for string similarity, entity matching, and data integration.

MatchForge aims to provide reusable algorithms and utilities for comparing strings, matching records, and evaluating matching techniques.

## Features

Currently implemented:

- Basic string normalization (trimming whitespace and converting to lowercase).

Planned features:

- String similarity algorithms.
- Text preprocessing.
- Two-column record matching.
- Algorithm evaluation.
- Schema matching.
